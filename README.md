# How the Turn Tables: The Grammaticalization of an Internet Meme

> **Course:** Computational Linguistics (Fall 2025)
> **Stack:** Python, PRAW (Reddit API), Pandas, NLTK

## TL;DR
A quantitative sociolinguistic study analyzing how a viral error from TV's *The Office* evolved into a grammatically distinct construction. Used Python to scrape and analyze 150 Reddit tokens to prove internet memes expand language rather than degrade it.

## The Research Question
How has the metathesized form *"how the turn tables"* evolved from a humorous error into a syntactically and semantically distinct construction from its origin *"how the tables have turned"*?

## Methodology & Stack
- **Data Collection:** Automated scraping via **Python/PRAW API**.
- **Dataset:** 150 tokens (75 canonical, 75 metathesized) from Reddit.
- **Analysis:** Applied Construction Grammar framework (Goldberg 2006) and quantitative coding for syntax, tone, and domain.

## Key Findings
- **Syntactic Freezing:** The meme form exhibits 99% syntactic freezing (used as a standalone interjection), whereas the original phrase functions as an embedded clause.
- **Semantic Shift:** 84.4% of meme usage is specialized for irony/humor, compared to 31.7% gloating for the canonical form.
- **Domain Specificity:** Political communities prefer the meme form (satirical frame), while gaming communities prefer the canonical form (literal victory).
